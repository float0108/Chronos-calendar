# Chronos 功能说明书

## 概述

Chronos 是一款跨平台桌面日历应用，支持日程管理、任务看板、笔记记录等功能。

---

## 核心功能

### 1. 日历视图 (App 窗口)

#### 1.1 月历显示
- 显示当前月份的日历网格
- 支持「整月模式」和「浮动周模式」
- 可隐藏周末列

#### 1.2 日期导航
- 点击导航按钮切换上一月/下一月
- 点击「今天」按钮快速回到今天
- 支持键盘快捷键：PageUp (上一月)、PageDown (下一月)

#### 1.3 日程管理
- 在日历单元格中显示日程列表
- 支持拖拽日程到其他日期
- 点击日程可编辑详情（描述、日期、完成状态）
- 右键单元格可设置颜色标记

#### 1.4 视图切换
- **待办视图 (todo)**：显示未完成的日程
- **已完成视图 (done)**：显示已完成的日程

#### 1.5 批量操作
- 支持批量添加重复任务
- 可设置按天/周/月周期循环

---

### 2. 待办窗口 (TodoWindow)

独立窗口，显示待办日程列表。

#### 功能
- 显示所有未完成日程
- 支持添加新待办
- 支持标记完成/删除
- 支持编辑日程内容和日期
- 数据与其他窗口实时同步

#### 快捷键
- `Enter`：确认添加
- `Escape`：取消添加

---

### 3. 看板窗口 (BoardWindow)

主任务看板视图，管理主任务及其子任务。

#### 功能
- 显示所有主任务卡片
- 支持创建/编辑/删除主任务
- 支持拖拽调整任务顺序
- 点击卡片打开任务详情窗口

#### 任务卡片信息
- 任务内容
- 完成状态
- 创建日期
- 子任务数量

---

### 4. 任务详情窗口 (TaskWindow)

从看板窗口打开，显示任务详情和子任务列表。

#### 功能
- 编辑任务标题和描述
- 管理子任务（添加/完成/删除/编辑）
- 设置创建日期和完成日期
- 查看任务所属的主任务

#### 子任务操作
- 勾选完成状态
- 编辑内容
- 修改日期
- 删除子任务

---

### 5. 搜索窗口 (SearchWindow)

全局搜索，跨所有窗口可用。

#### 功能
- 搜索日程内容
- 搜索主任务
- 搜索笔记
- 点击结果跳转到对应日期

---

### 6. 笔记窗口 (NoteWindow)

笔记管理功能。

#### 功能
- 创建/编辑/删除笔记
- 笔记按创建日期组织
- 支持笔记内容搜索

---

应用全局设置。

#### 基础设置 (BasicSettings)
- 开机自启动
- MCP 服务开关

#### 通用设置 (CommonSettings)
- 字体设置
- 单元格间距
- 单元格边框
- 周起始日 (周一/周日)
- 显示模式 (整月/浮动周)
- 浮动周数量
- 隐藏周末
- 描述对话框尺寸

#### 模式设置 (ModeSettings)
- 主题模式 (浅色/深色/跟随系统)
- 主色调
- 文字颜色
- 背景颜色/透明度
- 单元格颜色/透明度
- 边框颜色
- 毛玻璃效果开关

## 组件交互逻辑

### 日历单元格 (CalendarCell)

```
用户点击单元格
    ↓
显示日程编辑状态
    ↓
用户编辑日程 (输入内容/切换完成状态)
    ↓
用户完成编辑 (blur/按 Enter)
    ↓
调用 updateScheduleLines()
    ↓
保存到数据库
    ↓
后端 emit('schedule-changed')
    ↓
所有窗口收到事件
    ↓
各窗口调用 refreshSchedules() 重新加载
```

### 任务完成状态切换

```
用户在任意窗口切换任务完成状态
    ↓
调用 toggleScheduleStatus() 或 toggleMainTaskStatus()
    ↓
保存到数据库
    ↓
后端 emit('schedule-changed')
    ↓
所有窗口收到事件
    ↓
更新 UI 显示
```

### 拖拽调整日期

```
用户拖拽日程到新日期
    ↓
调用 moveScheduleWithUndo()
    ↓
保存到数据库
    ↓
后端 emit('schedule-changed')
    ↓
所有窗口收到事件
    ↓
更新日历显示
```

## 窗口交互逻辑

### 窗口层级

```
主窗口 (App)
    │
    ├── 设置窗口 (SettingsPanel)     ← 通过菜单打开
    │
    ├── 搜索窗口 (SearchWindow)      ← 通过菜单打开
    │
    ├── 笔记窗口 (NoteWindow)        ← 通过菜单打开
    │
    ├── 待办窗口 (TodoWindow)        ← 通过菜单打开
    │
    ├── 看板窗口 (BoardWindow)
    │       │
    │       └── 任务详情窗口 (TaskWindow)  ← 通过点击任务卡片打开
    │
    └── 右键菜单 (ContextMenu)       ← 通过右键点击单元格打开
```

### 窗口间通信

所有窗口通过 `schedule-changed` 事件通信：

```
任意窗口修改数据
    ↓
后端数据库操作完成
    ↓
后端 emit('schedule-changed')
    ↓
所有监听该事件的窗口收到通知
    ↓
各窗口自行刷新数据
```

### 事件监听注册

| 窗口 | 监听事件 | 刷新函数 |
|------|----------|----------|
| App | `schedule-changed` | `refreshSchedules()` |
| TodoWindow | `schedule-changed` | `loadSchedulesData()` |
| BoardWindow | `schedule-changed` | `loadTasks()` |
| TaskWindow | `schedule-changed` | `loadMainTasks()` + `loadSubTasks()` |

## 数据同步机制

### 同步流程

```
┌─────────────┐     数据库修改      ┌─────────────┐
│  前端窗口    │ ──────────────────→ │  Rust 后端   │
│             │                      │             │
│  调用 API   │                      │  执行 SQL   │
│  (invoke)  │                      │             │
└─────────────┘                      └──────┬──────┘
                                             │
                                    emit('schedule-changed')
                                             │
                      ┌─────────────────────┼─────────────────────┐
                      │                     │                     │
                      ↓                     ↓                     ↓
               ┌─────────────┐      ┌─────────────┐      ┌─────────────┐
               │ App 窗口    │      │ Todo 窗口   │      │ Board 窗口  │
               │             │      │             │      │             │
               │ listen()    │      │ listen()    │      │ listen()    │
               │     ↓       │      │     ↓       │      │     ↓       │
               │ refresh()   │      │ refresh()   │      │ refresh()   │
               └─────────────┘      └─────────────┘      └─────────────┘
```

### 前端不主动 emit

按照架构设计，前端**不主动 emit** 任何事件。所有数据变更通知由后端统一处理：

- 前端调用 API → Rust 执行 SQL → Rust emit('schedule-changed') → 所有前端窗口收到通知

## 导入导出功能

### CSV 导出

导出手动 CSV 文件，包含所有日程和颜色数据。

### JSON 备份

导出一个完整的 JSON 备份文件，包含：
- 所有日程
- 所有主任务
- 所有笔记
- 所有单元格颜色

### 数据导入

支持两种模式：
- **合并模式**：智能去重，相同 date+content 的记录会更新
- **覆盖模式**：清空现有数据后导入

## MCP 服务 (备忘录工具)

Chronos 提供 MCP (Model Context Protocol) 服务，允许 AI 助手操作日程数据。

### 可用工具

| 工具名 | 功能 |
|--------|------|
| add_schedule | 添加日程 |
| toggle_schedule | 切换日程完成状态 |
| get_schedules | 获取日期范围内的日程 |
| delete_schedule | 删除日程 |
| search_schedules | 搜索日程 |

### 端口配置

默认端口：3269
可在设置中修改

### 服务状态

- 可在设置中启用/禁用
- 启用后会在应用启动时自动启动
